# Alpha 发布说明草案

状态：独立 Core 源码仓库已公开，软件包 Alpha 尚未发布。当前 distribution 为 project-genesis、版本 0.2.0，版本号不代表已发行软件包。Apache-2.0、Copyright 2026 NanaseAki（仅有权许可的原创部分）、明确的第三方 CC0 例外及贡献政策已实施；详见 [许可范围](LICENSE_OPTIONS.md)。旧仓库独立保留 Private；当前公开入口及 PVR 的已验证范围见 [README](../README.md) 和 [SECURITY](../SECURITY.md)。源码公开不等于 Release 或 PyPI 发布获准。

已验收合并：M1、M2-A、M2-B1、P1/R4 与 P2-A。P2-A 历史基线通过 Python 3.12/3.13 各 270 项源码/安装回归。原字节干净基线已按批准的修订合同完成两版本地限定验收，各 289 项完整测试（其中 6 项 replacement），证据边界见 [发行准备说明](RELEASE_PREPARATION.md)。这些历史数量和 CI 结果不自动覆盖新增实现。

当前候选增加 Tkinter 文字聊天、显式 `local_preview` 会话保存/恢复和手动数据库备份、验证、恢复到新目录，默认仍为 FakeModel 与临时内存。候选实现已完成 Windows Python 3.12/3.13 各 467 项源码及无 `.git` 快照回归、两版离线 wheel/sdist 构建、Canary 和重建校验。另以合成数据完成 Python 3.13 原生备份页操作及当前显示缩放下默认、最小和最大化窗口的布局验收。远端 CI 以本候选 PR 的精确提交检查记录为准；本地验收不替代远端结果。变更后的文件集合须重新核对，旧收据不自动覆盖后续改动。

HTTP 适配器只连接明确指定的回环 IP；本候选上述自动回归使用自建合成 HTTP 服务，原生备份页验收不调用模型。两者都不是实际 Ollama/GPU 质量或性能验收，真实服务的执行证据须独立记录。桌面可显式配置经独立核查的本地 Ollama，默认演示不连接已有服务、不下载模型。

预览数据库和备份均为明文，保留已接收的失败及未完成输入；恢复不覆盖原库、不迁移旧合成数据、不自动打开或重试。未完成：流式输出、取消、严格端到端总时限、上下文预算、长期记忆与成长闭环、完整环境备份恢复、schema 迁移、加密、隐私删除与正式个人伙伴数据启用。有限的数据库恢复验收不等于硬件故障或完整灾难恢复保证。

发行准备使用固定提交和明确文件清单，在临时目录构建并核验 wheel/sdist。快照不带原 Git 历史、提交邮箱或私有审计材料；内容来源、版权和公开意愿仍须人工审查。

后续候选公开与软件包发行仍需核对相应文件集、贡献 CI 审批/权限、安全报告渠道及许可/第三方通知；已有公开仓库状态不替代这些检查。项目独立开发，与所引用项目或品牌没有声明的官方关联。
