已验收合并：M1、M2-A、M2-B1、P1/R4 与 P2-A。P2-A 历史基线通过 Python 3.12/3.13 各 270 项源码/安装回归。原字节干净基线已按批准的修订合同完成两版本地限定验收，各 289 项完整测试（其中 6 项 replacement），证据边界见 [发行准备说明](RELEASE_PREPARATION.md)。本候选仅作文档与有限 CI 静态适配；修改后的文件集、未来新目标和首次远端 CI 尚待单独验收，不能沿用原基线结果。

HTTP 适配器只连接明确指定的回环 IP；已验证自建合成 HTTP 服务，不代表已调用真实 LLM。没有真实 Ollama/GPU 质量或性能验收。默认演示不连接已有服务、不下载模型。

未完成：流式输出、取消、严格端到端总时限、上下文预算、长期成长闭环、完整备份恢复、schema 迁移、隐私删除与正式个人伙伴数据启用。持久化成功不等于具备灾难恢复能力。

发行准备使用固定提交和明确文件清单，在临时目录构建并核验 wheel/sdist。快照不带原 Git 历史、提交邮箱或私有审计材料；内容来源、版权和公开意愿仍须人工审查。

公开前还需核实目标仓库的附属内容、贡献 CI 审批/权限、安全报告渠道及最终快照的许可/第三方通知。项目独立开发，与所引用项目或品牌没有声明的官方关联。
